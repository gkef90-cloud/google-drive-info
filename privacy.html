Privacy Policy

Updated October 5, 2026.

My Google Drive is a personal configuration of rclone. It allows its owner to browse, download, upload, modify, and delete files in their own Google Drive using their Linux computer.

Google account data

rclone communicates with Google Drive using Google's API. Authorization tokens are stored locally in the owner's rclone configuration. Files may be downloaded or cached locally as needed.

This personal configuration does not send Google Drive files or authorization tokens to this website or GitHub. Google data is not sold or used for advertising.

Access and revocation

The owner can revoke this application's access through their Google Account's third-party connections settings. Local configuration files and cached data can be removed separately from the computer.

Website hosting

This informational website is hosted by GitHub Pages. GitHub may process visitor information under its own privacy policy.
